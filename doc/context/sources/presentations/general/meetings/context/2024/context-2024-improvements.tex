\starttitle[title=Development]

\startitemize
\startitem The \LUAMETATEX\ engine converges, we do a lot of experiments that can lead to extensions. \stopitem
\startitem The code base gets cleaner and we keep optimizing rendering and fixing issues. \stopitem
\startitem No (for the user) visible fundamental changes are expected but never say never. \stopitem
\startitem Stepwise more documentation gets added and existing manuals get extended. \stopitem
\startitem We try to report as much as possible on developments (ontarget, musings, articles). \stopitem
\startitem Quite some time goes in accommodating what is out of our sphere of influence. \stopitem
\stopitemize

\stoptitle

\starttitle[title=Interfacing]

\startitemize

        \startitem columns : \type {cw} and \type {cd} \stopitem

        \startitem size    : \type {hs} and \type {vs} \stopitem
        \startitem fonts   : \type {fs} (bodyfont), \type {fa} (asc), \type {fd} (desc) and \type {fc} (cap) \stopitem
    \stopitemize
\stopitem

\starttitle[title=Fonts]

\startitemize
\startitem We try to handle the more obscure \CFF\ (older \TYPEONE\ fonts). \stopitem
\startitem We have cleaner support for (two sided) italic correction. \stopitem
\startitem We added control over punctuation spacing (think uppercase in names) \stopitem
\startitem We have some extra checks for messy (math) fonts. \stopitem
\stopitemize

\stoptitle

\stopitemize
