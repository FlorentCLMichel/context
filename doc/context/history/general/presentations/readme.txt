This directory has a few presentations from the turn of the century. We keep them
around because they give an impression of developments at that time. It was the
time when pdfTeX introduced new features and PDF made some interesting
interaction possible. There were discussions about more drastic engine
development, for instance NTS.

In the end pdfTeX entered a stable state and the NTS project was abandoned. Also,
PDF was less stable than anticipated which means that some nice presentations
were dropped: movies, animations, javascript, media, widgets ... an everlasting
mess with therefore hardly any support in open source viewers.

Anyway, around that time new font technologies demanded upgrading engines which
is why XeTeX came around and later luaTeX joined in. In ConTeXt we went further
and ended up with LuaMetaTeX. Of course we didn't stop presenting developments
but if we found later presentations useful, we added those to the documentation
suite.
