    \starttitle[title={Presentations}]

        \start \hsize .6\textwidth

        This is a selection of three sets of presentations at meetings and a
        bunch of examples for some styles that come with \CONTEXT. In \MKIV\ some
        of the older styles have been dropped. There are more presentations,
        starting mid 1990's: some are lost, others make no sense showing (or have
        articles instead) and I have no time anyway to collect all of them.

        \blank

        We show the first four pages but you can find the complete files in the
        \CONTEXT\ distribution. This file is generated automatically so it's also
        a snapshot. Maybe some day I find the time to add some more.

        There are more files in the source tree because it doesn't make sense to
        provide all \PDF\ files. Some files are to be generated with \LUATEX\
        because they discuss something (\MKIV) that in the meantime has been
        superseded. Keep in mind that these talk are snapshots and might have
        presenting the state at that time, some experiments, or just have been
        teasers.

        \stop

    \stoptitle

    \startluacode

        local function show(where,pattern)
            context.StartShowFigures(where)
                local files = resolvers.findfiles(pattern)
                for i=1,#files do
                    local filename = files[i]
                    context.writestatus("presentation",filename)
                    context.ShowFigure(where,file.nameonly(filename),filename)
                end
            context.StopShowFigures()
        end

        show("Bacho\\TeX",          "presentations/bachotex/**/bachotex-*.pdf")
        show("\\ConTeXt\\ Meeting", "presentations/context/**/context-*.pdf")
        show("TUG",                 "presentations/tug/**/tug-*.pdf")
        show("Examples",            "presentations/examples/present-*.pdf")

    \stopluacode
